# Performance Report

## Steps

1. Pull data from ~~marketing analytics, ~~email marketing, and ~~CRM for the requested period. Accept uploaded exports if nothing is connected.
2. Compare to the prior period and to target.
3. Build a table by channel: spend, impressions, clicks, conversions, cost per acquisition, and pipeline or revenue influenced.
4. Explain what changed. Label every explanation as a **hypothesis** unless the data proves it.
5. Give three recommendations ranked by expected impact.

Note data caveats: attribution model, conversion lag, and any tracking gaps.
