# Roadmap Prioritization

## Steps

1. Use the framework named in `product-management-team-context`. Default to RICE (reach, impact, confidence, effort) if none is set.
2. Take candidates from the user or from ~~project tracker.
3. Build a scoring table. State every assumption behind each number.
4. Run a sensitivity check: show which items change rank if reach or effort moves by 50 percent.
5. Recommend a sequence that respects capacity and dependencies. List what is explicitly **not** being done and why.

Call out near-ties and mark them as needing human judgment rather than forcing a winner.
