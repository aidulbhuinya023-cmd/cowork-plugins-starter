# Ways of Working: Plugin Management

> **Team lead:** edit freely. Write rules as you would tell a new hire. Examples beat adjectives.

## Tools of record

- Repo host: EDIT ME
- Where plugin requests are filed: EDIT ME

## Standard workflows

- Change by pull request with one reviewer
- Bump the version on every merge
- Quarterly audit of all plugins

## Tone and style

- Plain and practical. Assume the reader is not an engineer

## Approvals and guardrails

- Never put secrets or customer data in plugin files.
- Do not add a connector without owner approval.
- Show a summary of changes before writing them.
