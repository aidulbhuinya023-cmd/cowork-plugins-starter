# Insight Summary

## Structure

1. **Headline**: one sentence with the key number
2. **Three supporting points**, each tied to evidence
3. **Chart suggestion**: type and what to put on each axis
4. **Caveats**: sample size, metric definitions, confounders, data freshness
5. **Recommended decision or next step**

Separate correlation from causation explicitly. Offer a three-sentence executive version and a longer version. Do not overstate certainty.
