# Trial Landscape

## Steps

1. Search ~~trial registry by condition, intervention, phase, and status as the user specifies.
2. Build a table: NCT ID, title, phase, status, sponsor, enrollment, primary endpoint, start and completion dates.
3. Summarize patterns: leading sponsors, mechanisms in play, common endpoints, and unaddressed populations.

Note that registry entries can be out of date. Link each trial by NCT ID. This is research information, not medical advice or patient guidance.
